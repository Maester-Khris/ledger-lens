# CPU profile: chat turns at 40 conversations (final code, after changes 1 and 2)

About 90 CPU-seconds sampled for about 1,000 turns: roughly 90 ms of Python CPU per turn. Limits: one run; the stub index skips the Pinecone client's own CPU; C code that releases the GIL is not counted.
